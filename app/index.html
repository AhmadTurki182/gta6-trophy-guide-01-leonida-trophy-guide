        Sources & about

        Every trophy's official name, description, grade, hidden flag and PSN count comes from the official PlayStation list as published by Exophase and PSNProfiles, which agree on every name, description and grade. Each guide in this app is written in my own words from that official description and cites those two sources beside it. Where the official list does not pin down a place or a step, the guide says so instead of inventing one — no location or step here is claimed without a source.

        This guide is an unofficial fan-made tracker. It has no Rockstar Games logo, official artwork, box art or game screenshots, and it works fully offline: it fetches nothing over the network, sets no cookies and registers no service worker. Progress is saved only in your browser (localStorage) and can be exported to a file and imported back.

        How to run it: serve the app/ folder with any static server and open index.html, or open the file directly. Everything it loads is a file inside app/.
